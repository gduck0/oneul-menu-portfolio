# 화면 사용 흐름

로그인 없이 체험하거나 가입 후 개인 설정을 저장한다. 오늘 식단과 내 설정 화면을 제공한다.

저장한 설정으로 하루 식단을 만들고, 끼니·구성 음식·분량을 바꿀 수 있다. 고정·직접 선택·제외 충돌 안내·직전 추천 변경 되돌리기를 제공한다. 저장 전 설정과 이번 식단의 조건은 구분하며, 분량을 모르는 직접 입력 음식은 영양을 임의로 추정하지 않는다.

화면은 [계정·설정](accounts-settings.md)과 [식단](planner.md) API를 사용한다. 실제 섭취 기록·평가·체험 자료 이관 화면은 아직 연결하지 않았다. 해당 버튼과 메뉴를 표시하지 않으며 관련 API도 초기 조회하지 않는다. 이미 기록한 끼니는 계획 기준으로 표시하고 조회만 한다.

실행은 [로컬 안내](run.md)를 따른다. 폰트·그림과 라이선스를 보존하며 그림은 음식 종류의 예시다. 화면 표시 열량은 개인 권장량 진단이 아니다.

## 회귀 검사

frontend 폴더에서 `pnpm test`로 이 단계에 포함된 자동 회귀 검사를 실행하고 `pnpm build`로 테스트 파일을 포함한 타입 검사와 배포 빌드를 확인한다. Node.js는 설치 안내의 검증 버전을 사용한다. 테스트 실행은 브라우저·API·DB를 시작하거나 기존 저장 자료를 수정하지 않는다.

음식 그림 연결, 목표 열량 차이·분량 미리보기, 준비 조건의 보존을 검사한다. 실제 기록·평가·이관 화면과 전용 검사는 후속 기록 단계에서 연결한다.

이 검사는 전체 브라우저 사용성 검사와 구분한다. 사용자 흐름은 해당 버전의 화면·API를 연결해 별도로 확인한다. 현재 주소와 화면에 맞지 않는 과거 대안 비교용 브라우저 검사는 현재 실행 검사 목록에 포함하지 않는다.
