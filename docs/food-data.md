# 음식 자료 가져오기

공공데이터포털의 [전국통합식품영양성분정보표준데이터](https://www.data.go.kr/data/15100064/standard.do)에서 보존한 JSON 5개 페이지를 사용한다. 다운로드한 5만 행 중 데이터 구분이 `D`인 음식만 가져온다. 원재료와 가공식품은 포함하지 않는다.

원본 디렉터리에는 `page-1.json`부터 `page-5.json`, 각 파일의 `page-N.manifest.json`이 있어야 한다. 수집 기록에는 페이지 번호, 행 수, SHA256, 출처 페이지와 수집 시각(`retrieved_at_utc`)을 보관한다. 원본과 수집 기록은 Git에서 제외한다.

```powershell
.\scripts\Migrate-Database.ps1 -Target test
.\scripts\Import-Nutrition.ps1 -Target test -Source C:\data\nutrition\snapshot
.\scripts\Test-Backend.ps1
```

개발 DB에 반영할 때는 마이그레이션과 가져오기 명령의 대상을 모두 `dev`로 지정한다. 기존 파일을 갱신한 뒤 같은 버전인 것처럼 다시 가져오지 않는다. 새로 내려받은 자료는 다른 디렉터리에 보존한다.

## 저장 기준

- 이름이 같아도 음식 코드가 다르면 별도 행으로 저장한다.
- 영양 기준량과 식품중량을 구분하고, g와 mL는 원본 단위를 유지한다.
- 열량·단백질·지방·탄수화물은 원본 숫자를 사용한다. 빈 값은 null이며 실제 0과 구분한다.
- DB에 손실 없이 저장할 수 없는 숫자는 반올림하지 않고 가져오기를 중단한다.
- 출처·자료 기준일·생성일·수집 시각·원본 행을 함께 보관한다.
- 같은 원본을 다시 가져오면 기존 버전과 행 수를 확인하고 중복 저장하지 않는다.
- 새 버전은 한 트랜잭션으로 저장한다. 실패하면 이전 활성 버전이 유지된다. 이전 음식 행은 수정하지 않으며 과거 버전을 재실행해도 다시 활성화하지 않는다.

테스트의 `nutrition-reference.json`은 공식 원본에서 고른 음식 9개의 표본이다. 전체 자료를 대표하지 않는다. 실패 조건을 위한 자료는 테스트 안에서 별도로 만든다.
