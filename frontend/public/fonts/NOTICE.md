# 포함한 글꼴

- Cafe24 Ssurround v2.0: 카페24(주), https://fonts.cafe24.com/. 공식 배포 ZIP의 WOFF2 원본과 저작권/사용 범위 안내 `Cafe24-LICENSE.pdf`를 포함한다. SIL Open Font License 1.1.
- SUIT Variable: SUNN/SUN, https://github.com/sun-typeface/SUIT. 공식 v2 웹폰트 WOFF2 원본과 저작권 안내/라이선스 전문 `SUIT-LICENSE.txt`를 포함한다. SIL Open Font License 1.1.

두 글꼴의 파일을 수정하지 않았다. 로컬 파일로 제공하며 실행 중 외부 글꼴 서버에 요청하지 않는다. 글꼴 자체를 별도 유료 판매하지 않는다. 원래 저작권 안내와 라이선스를 재배포할 때도 유지한다. OFL 1.1 전문은 동봉한 라이선스 파일에서 확인할 수 있다.
